# v0.3.0 原片内容精剪链路验证

日期：2026-11-16。本版新增由 Agent 编排的原片转写、内容取舍与重排、精确剪切、字幕重映射、响度整理和成片回转写/取帧验收。用户无需自行提供 SRT 或编写 JSON。语义剪辑由当前宿主 Agent 判断，脚本不额外调用付费模型 API。

## 本版实际验证

- 52 项测试通过（使用具备 zscale 的 FFmpeg 完整构建）；包含源/转写双指纹绑定、删剪全覆盖、禁止重复源词、重排字幕对时、草稿禁止渲染、数字/否定保护、旧回转写拒绝及不覆盖输出。
- 真实媒体边界测试验证非整帧补齐不会泄漏被删邻词、26ms 音视频偏移与精确 PCM 时钟、非整帧音频尾部、90°旋转仅应用一次。HLG 10-bit 测试与“仅重标 BT.709 标签”对照，验证真实像素映射；缺 zscale 时在创建输出前明确停止。
- 从全新 Python 3.9.6 虚拟环境按 requirements-asr.txt 安装成功，并使用已有离线 large-v3 模型完成真实 20 秒中文视频转写。该环境解析到 faster-whisper1.2.1、CTranslate2 4.9.0、NumPy2.0.2、PyAV15.1.0、ONNX Runtime1.19.2。模型权重从零下载未实测。
- 独立 Agent 只获得一段 20 秒原视频，按 Skill 新建转写、内容方案、字幕和三场景包装，实际输出 9.833333 秒、295 帧、1080×1920/30fps。最终回转写 35 个规范化字符完全一致，462 个剪后 AAC 包及时间一致，字幕与剪辑记录一致；测得 -16.15 LUFS、-1.17dBTP。实际场景与转场抽帧已检查；未直接听审，因此不标为最终发布验收。
- 另一条不随开源包分发的真实中文原片，从 209.151667 秒精简至 97.733333 秒（8 个保留片段、359/743 个源词），完成结论前置、两个案例与限定条件的内容取舍、10 场景包装。最终为1080×1920/30fps/2932帧，完整解码与剪后音轨包校验通过；测得 -16.25 LUFS、-1.25dBTP。最终回转写相似度98.4234%，定位出5处差异（语气词、同音代词、数字表示及同音词），其中`0-1`与`零到一`触发数字保护，报告保留NEEDS_REVIEW；没有仅凭相似度通过就宣称免复核。

前向使用实际发现并修正：手机HLG不能只重标成SDR；字幕自然分组必须在精剪方案中引用源词；浏览器读取剪后素材使用每秒关键帧；ASR字边界可能包含邻接短词，曾出现多带入“就是”，通过保留完整可听短语重新制作后回转写完全一致。默认相似度PASS仍可能含非保护词差异，Agent必须逐条检查差异。

## 完成度与限制

本版实测证明原片可由 Agent 走完整条精剪、字幕和包装链路，不代表任意素材都已达到发布水平。两条真实样本均未完成连续人工视听和逐字听审；所有未完成项保留为发布候选/NEEDS_REVIEW，没有交由用户编写基础剪辑工程。52项测试、回转写和取帧均不能证明口型或原声逐字真值。

HLG转SDR使用明确的1000nit基础层假设及Hable映射，不使用Dolby Vision动态RPU；真实HLG与合成HLG已测试，PQ路径尚无真实素材验收。ASR置信度不是准确性证明。当前Agent若不能直接听审，必须说明；模糊音、专名、数字仍需对原声复核。Windows/Linux、从零安装浏览器、跨多个源文件编剪未验收。源码包不包含真人素材、声音、私有转写/剪辑记录、模型权重、虚拟环境或渲染缓存。

以下保留v0.2包装能力的历史验证。其10组合完整矩阵不自动等同于v0.3新增剪辑链路已覆盖全部风格；v0.3真实整链路实测为深绿竖片适配。样式实现和依赖版本未变。
